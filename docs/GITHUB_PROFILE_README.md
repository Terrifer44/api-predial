## 🚀 Projeto em destaque

### 🏢 API-Predial — Gestão de manutenção predial

Plataforma web construída como Projeto Integrador do SENAI, voltada ao controle de solicitações de manutenção. Reúne três perfis: **morador**, **operário** e **administrador**.

- Registro e acompanhamento de chamados com imagens
- Triagem, atribuição de responsáveis e controle de prazos
- Comentários, notificações e relatórios
- Frontend React, API Node.js/Express e banco MySQL com Prisma
